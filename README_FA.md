# UI اصلی با اجرای نوتبوک

این بسته کامل، UI اصلی ارسال‌شده شما را همراه با اصلاحات اجرای نوتبوک برمی‌گرداند؛ UI دمو نیست.

۱. تمام اجراهای قبلی run.py را در PyCharm متوقف کنید.
۲. ZIP را در ریشه پروژه اصلی کنار run.py باز و فایل‌های هم‌نام را جایگزین کنید. پوشه instance و فایل‌های JSON و سایر فایل‌های xspatula را نگه دارید. پوشه app داخل این بسته کامل است.
۳. اگر وابستگی‌ها نصب نشده‌اند، در محیط پایتون پروژه اجرا کنید:
python -m pip install -r requirements-notebooks.txt
۴. سپس:
python run.py
۵. آدرس http://127.0.0.1:5000 را باز و Ctrl+F5 کنید. تب دموی پورت 5001 را ببندید.

اگر صفحه تنظیمات را می‌بینید، اطلاعات تنظیمات پروژه اصلی در instance فعلی ذخیره نشده است؛ این همان جریان UI اصلی است، نه دمو. تنظیمات را ذخیره کنید تا Import Data باز شود.

سه نوتبوک اصلی در xspatula/setup قرار دارند. اگر مسیر واقعی فرق دارد، app/notebook_jobs.py را اصلاح کنید. اجرای UI مقدار interactive=True را وارد نوتبوک می‌کند و تأییدهای متنی شناخته‌شده ساخت/حذف را رد می‌کند. اجرای مستقل پیش‌فرض False دارد و سؤال متنی می‌پرسد.

اطلاعات اتصال همچنان از scheme JSONهای فعلی خوانده می‌شود. این بسته JSONهای شما را تغییر نمی‌دهد و مقدار فرم UI را به‌صورت خودکار در آن‌ها نمی‌نویسد.

لاگ، پراگرس‌بار، ذخیره وضعیت سه آیکون و قفل مراحل در بسته موجودند. سایر گزینه‌های ورود داده همچنان جایگاه اتصال نوتبوک‌های بعدی هستند.

بررسی این نسخه: نگاشت‌های اصلی، پورت 5000، مسیر ذخیره workspace.sqlite3، پارامتر interactive و سینتکس فایل‌ها بررسی شد. تست‌های منطق اجرا و تأییدها در مراحل قبلی گذشتند؛ اجرای واقعی Windows/Jupyter/PostgreSQL در این محیط انجام نشده است.
